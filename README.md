# demo-orario – DEMO di Orario Facile e dell'app Luis@i

Versione **dimostrativa** del progetto `comprensivoalmese/orario` (IC Almese, Gruppo Wolf), per presentazioni.
Scuola e docenti sono **inventati**; la demo **non è collegata** al sito, a Google Drive o ai dati dell'Istituto.

- Si apre da qualsiasi telefono: pagina iniziale → **app Luis@i** (per i corsisti) oppure **Orario Facile** (per chi presenta).
- Parte **vuota**. Chi presenta, in Orario Facile: Esporta → «Importa da foglio di calcolo» →
  `FOGLIO-PROVA-scuola-fittizia-TEST.xlsx` → Orario → «Genera orario» → **«📤 Pubblica orario»**.
- Le sostituzioni (scheda Sostituzioni) si pubblicano per tutti con **«📤 Pubblica sostituzioni»**.
- «Pubblica» scrive i file in `dati/` di questo repository (con un token GitHub che chi presenta incolla nella pagina:
  resta solo in quella scheda del browser). I telefoni li rileggono ogni minuto.

Per ripartire da zero dopo la presentazione: rimetti vuoti `dati/orario-TEST.json` e `dati/sostituzioni-TEST.json`
(vedi `LEGGIMI-DEMO.md`).
